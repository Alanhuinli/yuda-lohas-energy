## ✨ 網站核心功能

1. **手機優先（Mobile-First）與全鍵盤無障礙操作**
   - 窄螢幕自動切換為可展開／收合的漢堡選單（支援 `Esc` 關閉與點擊連結自動收合）；全站按鈕、篩選器、輸入框與手風琴皆具備清晰 `:focus-visible` 焦點外框。
2. **限時優惠活動橫幅（含時區固定截止時間）**
   - 採用 ISO 8601 臺灣時區格式（`2026-12-31T23:59:59+08:00`），即時顯示「天、時、分、秒」；點擊「複製優惠碼」自動寫入剪貼簿並同步套用至下方預購單。活動截止後自動切換為「活動已結束」並停用折扣。
3. **8 款商品型錄：分類篩選 × 即時搜尋 × 詳情彈窗**
   - 分為「在地果韻能量」、「經典爆發補給」、「零卡輕盈機能」三大分類共 8 項商品，支援分類按鈕與關鍵字即時交集篩選，查無商品時提供一鍵重設按鈕。
   - 點擊「查看詳情」開啟彈窗，所有商品文字嚴格透過 `textContent` 安全寫入，支援右上角關閉鈕、點擊遮罩背景或按鍵盤 `Esc` 鍵關閉，並自動歸還鍵盤焦點。
4. **顧客口碑與 4 大常見問題（FAQ）**
   - 由 `js/data.js` 讀取在地情境評價與 4 個常見問題，FAQ 採用原生 `<button aria-expanded>` 架構，完全支援 `Tab`、`Enter` 與空白鍵展開／收合。
5. **免後端預購清單與明細匯出（LINE／IG 導購）**
   - 支援增減數量、單項移除、清空清單、優惠碼折抵試算；`localStorage` 僅儲存精簡之 `[{ id, qty }]`。
   - 檢查空清單與空白聯絡人暱稱並顯示友善提示；提供「**複製明細**」與「**下載 .txt**」（含 UTF-8 BOM 防亂碼），方便顧客直接貼到品牌 LINE 或 IG 私訊。

## 💻 本機預覽方式

本網站為純原生靜態網頁，無須安裝任何套件或編譯建置，可任選以下方式預覽：

1. **最快方式（直接開啟）**：在檔案總管直接雙擊 `index.html` 即可於瀏覽器完整運作。
2. **使用 Python 啟動本機靜態伺服器（推薦測試剪貼簿與網址參數）**：
   ```bash
   python -m http.server 8080
   ```
   接著於瀏覽器開啟 `http://localhost:8080`。
3. **使用 VS Code Live Server**：於 `index.html` 按右鍵選擇 `Open with Live Server`。

### ⏱️ 如何驗收限時活動「進行中」與「已過期」狀態？
- **驗收「進行中」狀態**：直接開啟 `index.html`（預設截止時間為 `2026-12-31T23:59:59+08:00`），頂端橫幅顯示「進行中」徽章、天時分秒每秒跳動倒數，且可點擊「複製優惠碼」套用 `YUDA88` 享 88 折。
- **驗收「已過期」狀態（兩種方式擇一）**：
  1. **網址參數快速測試（免改程式碼）**：在網址後方加上 `?promo=expired`（例如 `http://localhost:8080/?promo=expired` 或 `index.html?promo=expired`），橫幅立即切換為深灰底「活動已結束」、倒數歸零為 `00:00:00:00`、按鈕變為停用之「優惠已截止」，且預購清單自動恢復原價計算。
  2. **修改設定檔測試**：打開 `js/data.js`，將 `PROMO_CONFIG.deadline` 改為過去時間（如 `'2025-01-01T00:00:00+08:00'`），重新整理網頁即可驗證。

## 🚀 Vercel 直接部署指南

本專案為純原生靜態網站（根目錄直接包含 `index.html`），可在 Vercel **零建置（Zero-Build）直接部署**：

### 部署操作步驟
1. 將本專案推送至您的 GitHub 儲存庫（Repository）。
2. 登入 [Vercel Dashboard](https://vercel.com/dashboard)，點擊 **Add New...** → **Project**。
3. 在 **Import Git Repository** 清單中選擇本專案並點擊 **Import**。
4. 在專案設定畫面確認以下欄位：
   - **Framework Preset**：選擇 **`Other`**（代表純靜態網站，不執行框架編譯）。
   - **Root Directory**：維持預設 **`./`**（即 `index.html` 所在的專案根目錄）。
   - **Build and Output Settings**：維持預設關閉（Build Command 與 Output Directory 留空即可）。
   - **Environment Variables**：**完全留空**（本專案不使用任何外部 API 或金鑰）。
5. 點擊 **Deploy**，等待約 10–20 秒即完成全球 CDN 部署！

### 關於 `vercel.json` 快取設定說明
本專案包含 9 張高解析度商業商品圖片（位於 `/images/`），因此加入精簡的 `vercel.json`：
- 對 `/images/(.*)` 設定 `Cache-Control: public, max-age=604800, stale-while-revalidate=86400`（瀏覽器與 CDN 快取 7 天，背景平滑更新 1 天），大幅提升手機行動網路回訪時的載入速度，同時讓 `index.html`、`css/style.css` 與 `js/*.js` 保持預設即時更新策略。

### 部署後檢查清單
- [ ] 開啟正式網址（HTTPS），確認首屏與 8 張商品圖全部正常顯示無破圖（驗證 Linux 大小寫路徑完全相符）。
- [ ] 若您的正式網域與預設 `https://yuda-lohas-energy.vercel.app/` 不同，建議同步更新 `index.html` 內的 `og:url` 及將 `og:image`／`twitter:image` 換成完整 `https://<您的網域>/images/hero-energy.jpg`，讓外部社群爬蟲抓圖最穩定。

## 🧪 部署後人工測試步驟（五大驗收情境）

1. **手機導覽選單測試**
   - 以手機開啟正式網址（或用電腦瀏覽器 F12 切換 iPhone SE／375px 寬度）。
   - 點擊右上角「選單」按鈕確認導覽列順利展開；點擊「看商品」確認平滑捲動至商品區並自動收合選單；再次展開選單後按鍵盤 `Esc` 鍵確認可關閉選單。
2. **商品分類篩選與即時搜尋測試**
   - 點擊「零卡輕盈機能」確認畫面篩選出 2 款零糖商品；接著在搜尋框輸入 `白桃` 確認即時縮小為 1 款（雙重條件同時生效）。
   - 輸入不存在的關鍵字（如 `抹茶`），確認出現「找不到符合條件的能量飲」友善提示，點擊「清除搜尋與篩選條件」確認恢復全部 8 款商品。
3. **商品詳情彈窗測試**
   - 點擊任一商品的「查看詳情」，確認彈窗正確顯示圖片、價格、咖啡因規格與完整介紹。
   - 分別測試點擊「右上角 ✕」、點擊「彈窗外半透明黑底背景」以及按鍵盤 `Esc` 鍵，確認三種方式皆能正常關閉彈窗，且焦點回到原觸發按鈕。
4. **預購清單記憶與明細匯出測試**
   - 點擊頂部橫幅「複製優惠碼」（套用 `YUDA88`），將 2 款商品加入預購清單並測試 `+`、`−` 與「移除」按鈕，確認小計與 88 折後總額計算正確。
   - **重新整理網頁（F5）**，確認預購清單品項與數量透過 `localStorage` 完整保留（可在 F12 → Application → Local Storage 檢視 `yuda_lohas_preorder_v1` 僅存 `id` 與 `qty`）。
   - 保持「聯絡人暱稱」空白並點擊「複製明細」，確認出現紅色友善提醒且游標聚焦至暱稱欄；填寫暱稱與備註後，分別點擊「複製明細」與「下載 .txt」，確認剪貼簿文字與下載之 `.txt` 檔排版整齊無亂碼。
5. **社群分享預覽（Open Graph）測試**
   - 將正式網址貼入 LINE 聊天室輸入框、Discord、Facebook 分享偵錯工具或 [opengraph.xyz](https://www.opengraph.xyz/)，確認能正確抓取標題「育達樂活能量飲｜能量補充在舉手之間」、品牌描述與首屏鋁罐視覺縮圖。
